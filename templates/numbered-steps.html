P. 1

Writing better prompts

with prompt elements

❶ Persona

Define a “character” you want the LLM to embody. A famous person, a specific job related to the task or the topic.

❷ Task

This specifies what you want to achieve with the LLM’s help. The more clearly defined the task is, the better the LLM can fulfill the specific task.

❸ Context

Add relevant background information like examples, detailed explanations, uploaded documents to receive more specific answers.

❹ Format

Set rules for how the LLM should format its answer. You can define the writing style, tone, constraints or the structure of the output.
